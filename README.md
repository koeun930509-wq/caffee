# ☕ 커피 한 잔 후원하기

버튼 하나, 금액 하나(₩3,000)로 응원을 보내는 미니 웹앱입니다.

## 스택

- React (Vite)
- Supabase
- Vercel
- GitHub

## 개발 단계 (PDD)

1. 더미 UI — 화면과 상호작용 흐름만 구현 (완료)
2. 실데이터 연동 — Supabase 저장 + 실제 결제 연동
3. 관리자 알림 — 후원 발생 시 관리자에게 알림
4. 에러 처리 — 결제 실패/네트워크 오류 등 예외 처리

## 로컬 실행

```bash
npm install
npm run dev
```
